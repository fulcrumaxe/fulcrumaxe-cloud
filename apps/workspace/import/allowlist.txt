# apps/workspace/import/allowlist.txt
#
# Patterns are relative to the anchor `crates/fulc-shell/assets/` inside the
# source tar (import.mjs strips that prefix before matching), and to the
# root of apps/workspace/shell/ once extracted (checks.mjs matches directly).
#
# Glob syntax: `*` matches within one path segment; `**` matches across
# segments, including zero. Blank lines and lines starting with `#` are
# ignored.
#
# WS-A2 (D#37): extended from the WS-A1 baseline against the real jpos tree
# at commit 3d641544cc394649304cf1cb71b6860f44c44afb. `core/**`, `sdk/**`,
# `runtime/**` and `apps/themes/**` are written as one pattern per real
# extension rather than a blanket `dir/**`, because every one of those
# directories also contains `*.js.map` files in the real tree, and
# rules.mjs's PATH_SECRET_RE flags any `.map` path as secret-shaped
# regardless of allowlist status -- a blanket `**` there would select the
# .map files too and import.mjs would refuse the whole import before
# writing anything (assertNoSecretShapedEntries runs on every selected
# entry, before any write). `apps/activation/**` and `fonts/**` have no
# `.map` siblings in the real tree, so the blanket form stays safe there.
