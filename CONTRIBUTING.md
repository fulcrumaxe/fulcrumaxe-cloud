# Contributing

This repository is source-visible and proprietary (see `LICENSE`). Formal Hosting LLC may later
offer a paid self-hosted edition under a separate commercial licence, so every contribution has to
come with the right to use it that way.

**Outside contributions are not accepted until a contributor licence agreement (CLA) is in place.**
There is no CLA yet. Until there is one, pull requests from people outside the maintainers' team
are not reviewed or merged, whatever their content. Please do not spend time on one.

You can still:

- read the code and fork it on github.com, to the extent GitHub's Terms of Service allow;
- report a security problem privately to the maintainers, not in a public issue or pull request.

This page will change when the CLA exists, and the way to sign it will be described here.
